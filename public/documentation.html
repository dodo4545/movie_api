🎬 Movie API Documentation

Base URL: http://localhost:8080
Version: 1.0.0
Content Type: application/json

📋 Overview

Welcome to the Movie API! This RESTful API provides access to a curated collection of top movies with detailed information including titles, directors, release years, and genres. The API is built with Express.js and includes comprehensive logging and error handling.

🚀 Getting Started

To start using the API, make sure the server is running:

npm start # or node index.js

The server will start on port 8080 and you can access all endpoints listed below.

📍 API Endpoints

GET /

Description: Welcome endpoint that provides a greeting message and basic information about the API.

Response

Status: 200 OK
Content-Type: text/plain

Welcome to the Movie API! Your one-stop destination for top movie information.

Example Request

curl http://localhost:8080/

GET /movies

Description: Retrieves a list of the top 10 movies with detailed information including title, year, director, and genre.

Response

Status: 200 OK
Content-Type: application/json

{ "message": "Top 10 Movies", "count": 10, "movies": [ { "id": 1, "title": "The Shawshank Redemption", "year": 1994, "director": "Frank Darabont", "genre": "Drama" }, { "id": 2, "title": "The Godfather", "year": 1972, "director": "Francis Ford Coppola", "genre": "Crime, Drama" } // ... 8 more movies ] }

Movie Object Properties

Property Type Description
id number Unique identifier for the movie
title string The movie title
year number Release year of the movie
director string Director(s) of the movie
genre string Genre(s) of the movie

Example Request

curl http://localhost:8080/movies

POST /movies

Description: Demonstrates the API's ability to receive and process movie data (for testing purposes).

Request Body

Content-Type: application/json
Send any JSON data to test the body parsing functionality.

Response

Status: 200 OK
Content-Type: application/json

{ "message": "Movie created successfully", "receivedData": { // Your submitted data will be echoed back here } }

Example Request

curl -X POST http://localhost:8080/movies \ -H "Content-Type: application/json" \ -d '{"title": "New Movie", "year": 2025}'

GET /documentation.html

Description: Serves this API documentation page.

Response

Status: 200 OK
Content-Type: text/html

Returns this documentation page as HTML.

Example Request

curl http://localhost:8080/documentation.html

❌ Error Handling

The API includes comprehensive error handling and logging:

404 - Not Found

Status: 404 Not Found
{ "error": "Not Found", "message": "The requested resource was not found on this server", "url": "/requested-url" }

500 - Internal Server Error

Status: 500 Internal Server Error
{ "error": "Something went wrong!", "message": "Internal server error" }

📊 Logging

The API uses Morgan middleware for comprehensive request logging. All requests are logged to the server console with the following information:

  • Client IP address
  • Request timestamp
  • HTTP method and URL
  • Response status code
  • Response size
  • User agent

Application-level errors are also logged with detailed stack traces and request context.

🔧 Technical Details

Dependencies

  • Express.js: Web framework for Node.js
  • Morgan: HTTP request logger middleware
  • Body-parser: Node.js body parsing middleware

Features

  • RESTful API design
  • JSON response format
  • Static file serving
  • Comprehensive error handling
  • Request logging with Morgan
  • CORS-ready (can be extended)
