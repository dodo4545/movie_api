🎬 Movie API Documentation

Base URL: http://localhost:8080
Version: 1.0.0
Content Type: application/json

📋 Overview

Welcome to the Movie API! This RESTful API provides access to a curated collection of top movies with detailed information including titles, directors, release years, and genres. The API is built with Express.js and includes comprehensive logging and error handling.

🚀 Getting Started

To start using the API, make sure the server is running:

npm start # or node index.js

The server will start on port 8080 and you can access all endpoints listed below.

📍 API Endpoints Overview

🎯 Endpoint Summary Table

Request URL HTTP Method Response
Get all movies /movies GET JSON array of all movies
Get movie by title /movies/[Title] GET JSON object with movie data
Get genre info /movies/genre/[GenreName] GET JSON object with genre data
Get director info /movies/directors/[DirectorName] GET JSON object with director data
User registration /users POST JSON object with user data
Update user info /users/[Username] PUT JSON object with updated user data
Add to favorites /users/[Username]/movies/[MovieID] POST Text message confirming addition
Remove from favorites /users/[Username]/movies/[MovieID] DELETE Text message confirming removal
Delete user /users/[Username] DELETE Text message confirming deletion

📍 Detailed API Endpoints

GET /

Description: Welcome endpoint that provides a greeting message and basic information about the API.

Response

Status: 200 OK
Content-Type: text/plain

Welcome to the Movie API! Your one-stop destination for top movie information.

Example Request

curl http://localhost:8080/

GET /movies

Description: Returns a complete list of all movies in the database with detailed information including title, year, director, and genre.

Query Parameters

None

Request Body

None

Response Format

Status: 200 OK
Content-Type: application/json

[ { "id": 1, "title": "The Shawshank Redemption", "year": 1994, "director": { "name": "Frank Darabont", "bio": "American director and screenwriter", "birth": "1959" }, "genre": { "name": "Drama", "description": "Serious narrative fiction" }, "imageURL": "shawshank.jpg", "featured": true } ]

Example Request

curl http://localhost:8080/movies

GET /movies/:title

Description: Returns detailed information about a specific movie by its title.

URL Parameters

title (string): The exact title of the movie (case-sensitive)

Request Body

None

Response Format

Status: 200 OK
Content-Type: application/json

{ "id": 1, "title": "The Shawshank Redemption", "year": 1994, "director": { "name": "Frank Darabont", "bio": "American director and screenwriter", "birth": "1959" }, "genre": { "name": "Drama", "description": "Serious narrative fiction" }, "imageURL": "shawshank.jpg", "featured": true }

Example Request

curl http://localhost:8080/movies/The%20Shawshank%20Redemption

GET /movies/genre/:genreName

Description: Returns detailed information about a specific genre including its description and characteristics.

URL Parameters

genreName (string): The name of the genre (e.g., "Drama", "Action", "Comedy")

None

Response Format

Status: 200 OK
Content-Type: application/json

{ "name": "Drama", "description": "Drama films are serious presentations or stories with settings or life situations that portray realistic characters in conflict with either themselves, others, or forces of nature." }

curl http://localhost:8080/movies/genre/Drama

Response Format

Status: 200 OK
Content-Type: application/json

{ "name": "Frank Darabont", "bio": "American director, screenwriter, and producer known for his work on drama films.", "birth": "1959", "death": null }

POST /users

Description: Allows new users to register by providing username, password, email, and birthday.

Query Parameters

None

Request Body Format

Content-Type: application/json

{ "username": "moviefan123", "password": "securePassword", "email": "user@example.com", "birthday": "1990-01-15" }

Response Format

Status: 201 Created
Content-Type: application/json

{ "id": 1, "username": "moviefan123", "email": "user@example.com", "birthday": "1990-01-15", "favoriteMovies": [] }

Example Request

curl -X POST http://localhost:8080/users \ -H "Content-Type: application/json" \ -d '{"username": "moviefan123", "password": "securePassword", "email": "user@example.com", "birthday": "1990-01-15"}'

PUT /users/:username

Description: Allows users to update their personal information including username, password, email, and birthday.

URL Parameters

username (string): The current username of the user

Request Body Format

Content-Type: application/json

{ "username": "newUsername", "password": "newPassword", "email": "newemail@example.com", "birthday": "1990-01-15" }

Response Format

Status: 200 OK
Content-Type: application/json

{ "id": 1, "username": "newUsername", "email": "newemail@example.com", "birthday": "1990-01-15", "favoriteMovies": [1, 3, 5] }

Example Request

curl -X PUT http://localhost:8080/users/moviefan123 \ -H "Content-Type: application/json" \ -d '{"email": "newemail@example.com"}'

❌ Error Handling

The API includes comprehensive error handling and logging:

404 - Not Found

Status: 404 Not Found
{ "error": "Not Found", "message": "The requested resource was not found on this server", "url": "/requested-url" }

500 - Internal Server Error

Status: 500 Internal Server Error
{ "error": "Something went wrong!", "message": "Internal server error" }

📊 Logging

The API uses Morgan middleware for comprehensive request logging. All requests are logged to the server console with the following information:

  • Client IP address
  • Request timestamp
  • HTTP method and URL
  • Response status code
  • Response size
  • User agent

Application-level errors are also logged with detailed stack traces and request context.

🔧 Technical Details

Dependencies

  • Express.js: Web framework for Node.js
  • Morgan: HTTP request logger middleware
  • Body-parser: Node.js body parsing middleware

Features

  • RESTful API design
  • JSON response format
  • Static file serving
  • Comprehensive error handling
  • Request logging with Morgan
  • CORS-ready (can be extended)
